# Bracelet Store Website

A beautiful, responsive e-commerce website for handmade bracelets.

## Features

- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Product Grid**: Displays bracelets with images, prices, and buy buttons
- **Smooth Navigation**: Smooth scrolling between sections
- **Modern Styling**: Soft aesthetic with a pastel color palette
- **Interactive Elements**: Hover effects and smooth transitions

## Files

- `index.html` - Main HTML structure
- `styles.css` - Styling and responsive design
- `script.js` - JavaScript functionality and interactivity
- `README.md` - This file

## Getting Started

1. Clone or download this repository
2. Open `index.html` in a web browser
3. The website will load with all products and styling

## Customization

To customize the website:

- Edit the brand name in `index.html` (line 9 and header)
- Modify colors in `styles.css` (search for color codes like `#f8e1e7`)
- Add/edit products in `script.js` in the `products` array
- Update contact information in `index.html`
